## 1.0.8
- **Annotations** — attach notes to any tracked interval from the menu bar or the reports timeline. Enable "Prompt for annotation when stopping" in Preferences to be asked automatically each time a task stops or switches.
- **Add tag… submenu** — add a second tag alongside the running one directly from the menu, without stopping. Recent tags appear at the top; older tags are nested underneath.
- **Annotations table in reports** — a new table below the pie chart lists every annotated interval for the period, sorted by end time. Right-click to copy as CSV.
- **Annotation text on timeline bars** — annotations appear as small text inside each bar in the report timeline (when the bar is wide enough), and always in the hover tooltip.
- **Clear filter button in reports** — a "✕ Clear filter" button appears next to the active filter label, making it easy to reset tag filtering with one click.
- **Help window** — "Help…" in the menu opens a reference guide covering every menu item and feature.

## 1.0.7
- **Report window** — Day, Week, Month and Custom range tabs with interactive timeline, pie chart, and summary table. Right-click any interval bar to annotate or view raw data. Right-click the summary table to copy as CSV.
- **Preferences window** — consolidated Preferences & About panel with all settings in one place.
- **Pause on screen lock** — optionally stop tracking automatically when the screen locks and resume on unlock.
- **Show empty days** — toggle whether days with no tracked time appear in week/month reports.
- **Daily work target** — set a daily hour target used for the % of target column and pie chart remainder.
- **Recent tags range** — configure how far back "recent" tags extend in the menu (default: this month).
- **Older tags submenu** — tags outside the recent range are grouped into a collapsible submenu.
- **Start at login** — add Arête to macOS login items from within Preferences.

## 1.0.6
